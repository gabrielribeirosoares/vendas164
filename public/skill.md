# Vendas 164 — Skill

## Identidade

Plataforma brasileira de pré-vendas e gestão de reservas de miniaturas colecionáveis em escala 1:64.

## Habilidades

### Navegar Catálogo
Permite visualizar os produtos disponíveis em pré-venda de uma loja cadastrada, filtrando por marca, escala ou modelo.

### Reservar Miniatura
Permite que um colecionador reserve uma miniatura pagando o sinal via PIX (copia e cola).

### Acompanhar Reserva
Permite consultar o status de uma reserva: sinal pago, saldo pendente, prazo de entrega e código de rastreamento.
